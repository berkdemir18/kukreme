# Kükreme

Tesla'da gaz ve frene anında tepki veren gerçek motor sesi. Tarayıcıda çalışır; arabanın ekranından ya da telefondan açılır.

- **Yolda:** Tesla ekranında GPS (saniyede ~10 konum) ile hızlanma/yavaşlama 0.2–0.4 sn içinde yakalanır. Telefonda ayrıca ivmeölçer kullanılır.
- **Test:** Ekrandaki gaz/fren pedalları; araç dururken fren + gaz = boşta gaz.
- **Ses:** Gerçek motor kayıtları devire göre granüler çalınır; sentetik motor sesi yoktur.
- **Kendi sesini ekle:** Bir motor sesi dosyası yüklenir, tarayıcıda analiz edilir ve sadece o cihazda saklanır.
